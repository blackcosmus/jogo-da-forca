# Jogo da Forca

Meu primeiro projeto em Python — um jogo da forca completo, rodando no terminal.

## Como jogar

```bash
python3 jogo_da_forca.py
```

Escolha a dificuldade e tente adivinhar a palavra antes que o boneco se complete:

- **Fácil** — palavra curta
- **Médio** — palavra média
- **Difícil** — palavra longa (boa sorte)

Você tem 6 tentativas. Letras repetidas não contam como erro.

## O que eu pratiquei aqui

- Funções (`def`) e organização do código
- Laços `while` e condição de vitória/derrota
- Listas, `len()`, `enumerate()`
- `input().lower().strip()` e dicionários
- Desenho ASCII do boneco da forca

Feito com a ajuda do meu sensei de programação.
